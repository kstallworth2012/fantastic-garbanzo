# Stock Trading Data Extractor 

This is a stock data extractor program that will extract data from massive.com 
I'm using the free version and I'm only allowed to get a certain amount of data. 
So I had to create a function to run the next url of data. The function would then make three additional 
requests. 
I then put each api request of data into a csv file.
